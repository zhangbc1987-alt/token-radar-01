How the value is built — read this before trusting a rank

Implied value = TVL × peer multiple × growth × maturity × chains × tier. Peer multiple is the median market-cap/TVL of token-bearing protocols in the same category (at least 3 peers, else the whole-market median 0.21), clamped to 0.05–0.60. Growth is the 7-day TVL change clamped to −50…+100% (×0.80…×1.40). Maturity is 0.70–1.00 from how long the protocol has run with no token (listed_at → snapshot date, 3 years max; unknown counts as 1 year). Chains adds 3% per extra chain (max +15%).

Tiers. Watchlist — the snapshot's own 40 (TVL ≥ $50M, no token recorded). Early finds — clean pre-token protocols below the floor. Flagged — a wrapped, staked or bridged product of a token that already trades; listed apart and not ranked, because no discount makes a wrapped product's “launch” honest — farm it for yield, not for a new token. Live tokens are shown apart, at the market's own market cap — never mixed into the ranked board.

Words matter. “Records no token” means DefiLlama's record carries none — it is not proof a token does not exist. Implied value is this radar's own claim from the snapshot's figures, never a prediction that a token will be issued, when, or at what price. No protocol name is special-cased: the same formula scores every row. Snapshot: DefiLlama, 2026-11-14.
